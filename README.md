# ♿ AccessLab – Plataforma Inteligente de Gestão da Acessibilidade

O **AccessLab** é uma plataforma web desenvolvida para auxiliar na **gestão da acessibilidade dos laboratórios de informática** de instituições de ensino.

O sistema centraliza informações sobre laboratórios, equipamentos adaptativos, condições de acessibilidade, solicitações e manutenções, apoiando a **CAPNE e a gestão institucional** na tomada de decisões e no planejamento de melhorias.

---

# ✨ Principais Recursos

* 🔐 **Login:** acesso para administradores e gestores autorizados.
* 🏫 **Laboratórios:** cadastro e gerenciamento dos ambientes.
* ♿ **Equipamentos:** cadastro, consulta, edição e exclusão de equipamentos adaptativos.
* 📝 **Solicitações:** registro e acompanhamento de adaptações.
* 🔧 **Manutenções:** registro e acompanhamento das manutenções.
* ☑️ **Checklists:** verificação das condições de acessibilidade.
* 📊 **Relatórios:** informações sobre a situação dos laboratórios.
* 💰 **Orçamentos:** planejamento de aquisição de equipamentos e adaptações.
* 📈 **Dashboard:** indicadores para auxiliar a gestão.

---

# 🎯 Objetivo

Gerenciar a acessibilidade dos laboratórios de informática, centralizando informações e facilitando o acompanhamento das demandas, o planejamento de melhorias e a definição de prioridades.

---

# 👥 Usuários

* **Administrador:** gerencia usuários e configurações.
* **Gestão da CAPNE:** acompanha demandas e gerencia a acessibilidade.
* **Gestão Institucional:** acompanha indicadores e relatórios.
* **Técnicos de Laboratório:** registram informações e realizam adaptações e manutenções.

---

# 🛠️ Tecnologias

* **Java**
* **HTML**
* **CSS**
* **API REST**
* **MySQL**

O sistema utiliza uma arquitetura baseada em **API REST** para comunicação e **MySQL** para armazenamento dos dados.

---

# 📋 Requisitos

O sistema deve permitir:

* Login seguro de usuários autorizados;
* Cadastro e gerenciamento de laboratórios;
* Cadastro e gerenciamento de equipamentos adaptativos;
* Registro de condições de acessibilidade;
* Gerenciamento de solicitações e manutenções;
* Geração de checklists, relatórios e orçamentos;
* Visualização de dashboards e indicadores.

---

# 🚫 Fora do Escopo

Nesta primeira versão, o sistema não contempla:

* Acesso direto dos estudantes;
* Compras automáticas;
* Controle de empréstimos de equipamentos;
* Processos acadêmicos ou administrativos;
* Integração com SUAP, SIGAA ou outros sistemas externos.

---

# 🚀 Como executar

1. Instale as tecnologias necessárias: **Java, MySQL e ferramentas para desenvolvimento web**.
2. Configure o banco de dados MySQL.
3. Configure a API REST.
4. Execute o projeto.
5. Acesse a aplicação pelo navegador.
